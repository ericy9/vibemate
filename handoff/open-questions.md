# 待验证与待决定事项

## 已确定的 Agent 协议基线

- 当前实现按 Codex 0.147.0 和 Copilot 1.0.79 的 Hook 契约映射。
- Codex 无决定输出 `{}`；Copilot 无决定保持空 stdout。
- 生命周期本机投递预算为 1 秒，权限等待预算为 9 分钟，Agent Hook 配置为
  10 分钟。
- 合成测试已覆盖服务缺失、格式错误和空决定回退；真实 CLI 行为仍列在验证要求。

## 协议设计

- Protocol v1 Schema 和载荷限制见 `docs/protocol-v1.md`。
- 会话存储已实现按时间瞬间判断乱序、会话内事件去重和每轮完成去重。
- 原始诊断事件保留多少条、保留多久？

## 本机运行时

- Core Service 已确定使用 Node.js + TypeScript；仍需确定最终由独立进程运行，
  还是由 Electron 主进程负责启动和监督。
- 动态端口信息写入 `~/.vibemate/runtime.json`，权限为 `0600`，并通过
  capability token 和单实例锁保护。
- 开发观察器第一版使用终端界面、SSE 网页还是 WebSocket 网页？

## 验证要求

- 使用真实 Codex CLI 完成状态和 Allow/Deny 测试。

- 验证两个以上并发终端不会串会话或串权限。
- 验证服务关闭、网络中断、超时和格式错误时的原生回退。
- 检查日志和持久化数据中不存在已知敏感载荷。
